# Extraction evaluation protocol

The extraction pipeline is implemented and tested, but one successful real-provider
fixture is not a representative accuracy benchmark. This protocol requires a
separate, human-adjudicated ground-truth file before any accuracy result is reported.

## Prepare labels

1. Sample listings independently of model success/failure and preserve the sampling
   rule, source, date, language mix and sample size.
2. Two reviewers label explicit facts from the original text. Record both pseudonymous
   reviewer IDs and the adjudicator ID; resolve disagreements before setting
   `annotation_status` to `adjudicated`.
3. Give each row a stable `record_id` and SHA-256 of the exact UTF-8 `source_text`;
   do not include prediction output in the annotation interface. Use
   `docs/templates/extraction-ground-truth.schema.json` to validate the JSONL objects.
4. Put only fields actually reviewed in `ground_truth`. Use `null` when a reviewed
   field is absent. Set numeric tolerances before looking at model predictions.

Predictions are a separate JSONL file. Each row contains `record_id`, `status`,
`attempts`, `latency_seconds`, and, for a successful record, the provider's parsed
`output` (`fields`, `confidence`, `evidence`). A fixture generated by the stress agent
may test the harness but must be labelled **synthetic** and cannot establish real-data
accuracy.

## Run

```bash
python -m research.extraction_evaluation \
  --annotations path/to/adjudicated-ground-truth.jsonl \
  --predictions path/to/extraction-predictions.jsonl \
  --output runtime/research/extraction-evaluation/metrics.json
```

The report contains field-level and micro precision/recall/F1, record exact match,
numeric tolerance accuracy, completeness, evidence validity, processing success,
invalid-output and retry rates, plus mean/p95 latency. A mismatched non-null value is
both a false positive and a false negative. Missing predictions count as failures.

No representative human-labelled dataset is committed at present, so these metrics
remain **not experimentally verified** until that dataset and its sampling protocol
exist.
